# El Atraco

Escape room educativo por bandas (RPMI · fuentes multimedia).

- `#/jugar` — alumnos · `#/proyector/CÓDIGO` — pantalla del aula · `#/profe` — modo profesor
- Añade `?local=1` a la dirección para probar sin Firebase (sincroniza pestañas del mismo navegador).
- Configuración (Firebase, contraseña, fases, dinero): `js/config.js`.
